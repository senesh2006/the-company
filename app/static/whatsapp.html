WAHA Server Quickstart (Docker)

Run WAHA locally or on Railway / your VPS in one terminal command:

docker run -it -p 3000:3000/tcp -e WHATSAPP_DEFAULT_ENGINE=WEBJS devlikeappro/waha
1Set WAHA_BASE_URL=http://localhost:3000 in your .env.
2Point WAHA Webhook to /api/v1/whatsapp/webhook for instant task ingestion.
3Text your WhatsApp number anytime to assign tasks to your Personal Assistant!
Agents can also proactively send WhatsApp notifications using the send_whatsapp_message tool.
